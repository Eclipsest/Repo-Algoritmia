# 1. Saludo

**Descripción:** Este algoritmo solicita el nombre del usuario y lo utiliza para mostrar un mensaje de bienvenida personalizado.

**Lógica:**
1. Se declara una variable de tipo carácter llamada nombre.
2. Se solicita al usuario que ingrese su nombre.
3. Se almacena el nombre ingresado.
4. Se muestra un saludo utilizando el nombre proporcionado.

**Ejemplos de ejecución:**

**Prueba 1:**

¿Cómo te llamas?
> Roland

Hola, Roland. Bienvenido a Algoritmia

**Prueba 2:**

¿Cómo te llamas?

> Felipe

Hola, Felipe. Bienvenido a Algoritmia

# 2. Edad en días

**Descripción:** Este algoritmo calcula aproximadamente cuántos días ha vivido una persona a partir de su edad en años.

**Lógica:**
1. Se declaran dos variables enteras: edad y dias.
2. Se solicita al usuario que ingrese su edad.
3. Se multiplica la edad por 365 para obtener los días vividos.
4. Se muestra el resultado en pantalla.

**Ejemplos de ejecución:**

**Prueba 1:**

¿Cuántos años tienes?

> 19

Has vivido 6935 dias

**Prueba 2:**

¿Cuántos años tienes?

> 49

Has vivido 17885 dias

# 3. Propinas

**Descripción:** Este algoritmo calcula el valor de una propina, la suma al total de la cuenta y divide el resultado entre el número de personas.

**Lógica:**
1. Se solicita el valor total de la cuenta.
2. Se solicita el porcentaje de propina.
3. Se solicita la cantidad de personas que dividirán la cuenta.
4. Se calcula la propina multiplicando la cuenta por el porcentaje y dividiendo entre 100.
5. Se suma la propina al valor de la cuenta.
6. Se divide el total entre el número de personas.
7. Se muestra cuánto debe pagar cada persona.

**Ejemplos de ejecución:**

**Prueba 1:**

> 120000

> 10

> 20

Cada uno paga: $6600

**Prueba 2:**

> 50000

> 5

> 6

Cada uno paga: $8750

# 4. Promedio de notas

**Descripción:** Este algoritmo solicita tres calificaciones y calcula el promedio de las notas ingresadas.

**Lógica:**
1. Se declaran cuatro variables de tipo real: nota1, nota2, nota3 y promedio.
2. Se solicita al usuario que ingrese las tres notas.
3. Se suman las tres calificaciones.
4. El resultado de la suma se divide entre 3.
5. Se muestra el promedio obtenido.

**Ejemplos de ejecución:**

**Prueba 1:**

Ingrese la primera nota:

> 4

Ingrese la segunda nota:

> 3.5

Ingrese la tercera nota:

> 4.5

El promedio es: 4

**Prueba 2:**

Ingrese la primera nota:

> 3

Ingrese la segunda nota:

> 3

Ingrese la tercera nota:

> 4

El promedio es: 3.3333333333
